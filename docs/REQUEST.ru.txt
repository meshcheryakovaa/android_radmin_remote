Ты senior Android/network developer. Нужно спроектировать и реализовать рабочий прототип Android-приложения, которое подключает Android-устройство к существующим сетям Radmin VPN через открытую реализацию протокола OpenRad, при этом исходящие соединения OpenRad должны иметь возможность работать через прокси-транспорт.

Цель первого этапа:

Android APK
→ HTML/CSS/JS интерфейс
→ Kotlin bridge
→ OpenRad Android engine
→ Proxy transport
→ Интернет
→ инфраструктура Radmin VPN

Главное требование: приложение должно быть единым APK. Не использовать одновременно отдельные приложения Happ + OpenRad. Не должно быть конфликта двух Android VpnService.

В качестве исходной реализации Radmin VPN использовать проект:

https://github.com/gringoestrangeiro/openrad

Особое внимание уделить Android-клиенту:

# 5. Proxy transport

Это ключевая часть проекта.

OpenRad сейчас создаёт собственные TCP/UDP-соединения.

Нужно абстрагировать транспортный слой.

Ввести интерфейс условного вида:

interface OutboundTransport {
    connectTcp(host, port)
    connectUdp(...)
}

Реализовать минимум:

DirectTransport

и:

ProxyTransport

DirectTransport работает как существующий OpenRad.

ProxyTransport отправляет управляющие TCP-соединения OpenRad через прокси.

Первый прототип желательно сделать через наиболее простой transport, например:

SOCKS5

а затем предусмотреть архитектуру для:

VLESS
VLESS + Reality
Trojan
Shadowsocks

Если полноценное внедрение Xray/sing-box в первый прототип слишком значительно усложняет проект, сначала реализовать:

OpenRad
→ SOCKS5
→ внешний proxy

Но архитектура должна позволять позже заменить SOCKS5 на VLESS/Reality.

# 6. Важная проблема VpnService.protect()

Учитывать существующее использование:

VpnService.protect(socket)

в OpenRad.

Нужно не допустить петли вида:

OpenRad socket
→ TUN
→ OpenRad
→ TUN
→ ...

Чётко определить, какие сокеты должны:

- проходить через TUN;
- bypass TUN;
- отправляться через proxy.

Прокси-соединение должно физически выходить в интернет через обычный Android uplink.

Опиши маршрутизацию подробно.

# 18. Главный критерий успеха

На Android:

1. Пользователь запускает одно приложение.
2. Нажимает Connect.
3. Приложение подключается через выбранный proxy.
4. Получает Radmin/OpenRad IP вида:

26.x.x.x

5. Подключается к существующей Radmin VPN network.
6. Видит Windows-компьютеры, подключённые обычным Radmin VPN.
7. Может обращаться к их IP:

26.x.x.x

8. Остальной интернет телефона продолжает работать.

Главный принцип архитектуры:

HTML — интерфейс.

Kotlin — Android integration.

OpenRad — Radmin protocol engine.

Proxy transport — способ доставки соединений OpenRad через доступный внешний канал.

VpnService — единственная системная VPN-сессия Android.
